# 👥 Team Member Guide - Database Access

## 🎯 For Developers

You can now access the production database through phpMyAdmin!

---

## 🔐 Access Information

**Ask your team lead for:**
- Server IP Address
- Database Username
- Database Password

---

## 📱 How to Access

1. **Open phpMyAdmin**:
   ```
   http://SERVER_IP:8081
   ```

2. **Login**:
   - Server: `mysql`
   - Username: `ddas_user` (or what you were given)
   - Password: (provided by team lead)

3. **Select Database**: `dam_disaster_db`

---

## ✅ What You Can Do

- View all tables
- Browse data
- Run SQL queries
- Export database
- Import data
- Modify records
- Create new tables

---

## ⚠️ Important Rules

1. **Be Careful**: You're working with production data
2. **Always Backup**: Export before making changes
3. **Test First**: Test queries on local first if possible
4. **Communicate**: Let team know if you make schema changes
5. **Never Delete**: Unless you're absolutely sure

---

## 🔧 Common Tasks

### View Data
1. Click on `dam_disaster_db` database
2. Click on table name
3. Click "Browse" to see data

### Run SQL Query
1. Click "SQL" tab
2. Enter your query
3. Click "Go"

### Export Database
1. Click "Export" tab
2. Choose "Quick" or "Custom"
3. Click "Go" to download

### Import Data
1. Click "Import" tab
2. Choose file
3. Click "Go"

---

## 🆘 Need Help?

- Can't login? → Check with team lead for credentials
- Forgot password? → Contact team lead
- Made a mistake? → Restore from backup immediately

---

## 🔒 Security

- **Don't share credentials** publicly
- **Use secure connections** when possible
- **Log out** when done

---

## 📞 Contact

For access issues or questions, contact your team lead.
