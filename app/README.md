# Dam Disaster Alert System

A mobile application designed to provide early warning alerts and real-time monitoring for dam water levels and potential disaster situations. This app aims to ensure public safety by notifying users in high-risk areas immediately.

## 🚀 Features

- **Real-time Alerts:** Instant push notifications for rising water levels.
- **Live Monitoring:** View current status of nearby dams.
- **Emergency Maps:** Evacuation routes and safe zones.
- **User Reporting:** Community-driven updates on local conditions.

## 📱 Tech Stack

- **Framework:** React Native (Expo)
- **Backend:** Firebase / Node.js
- **Maps:** Google Maps API
